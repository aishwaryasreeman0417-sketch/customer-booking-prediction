Machine Learning project to predict customer booking completion using Random Forest.
# Customer Booking Prediction using Machine Learning

## Overview

This project predicts whether a customer will complete an airline booking using machine learning techniques.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Project Workflow

* Data Exploration and Preprocessing
* Feature Encoding
* Random Forest Model Training
* Model Evaluation
* Feature Importance Analysis

## Results

* Accuracy: 85.51%
* Mean Cross-Validation Score: 50.55%

## Key Insights

The analysis identified important factors influencing booking completion, including purchase lead time, flight duration, route, and booking origin.
